# Cursor CLI in tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Cursor Agent to the `tools` feature while reserving `agent` for Cursor and removing Grok's alias.

**Architecture:** Install CLIs as the remote user and expose stable commands from `/usr/local/bin`. Remove Grok-owned `agent` links after the Grok installer, then install Cursor and expose Cursor's `agent` from `/usr/local/bin`.

**Tech Stack:** Dev Container Feature manifest JSON, Bash installer, Dev Container Feature scenario tests.

## Global Constraints

- `installCursor` is boolean and defaults to `true`.
- Invoke Cursor as the remote user with `curl https://cursor.com/install -fsS | bash`.
- Grok remains available as `grok` but must never supply `agent`.
- `/usr/local/bin/agent` points to Cursor when Cursor is enabled.
- Bump the `tools` feature version.
